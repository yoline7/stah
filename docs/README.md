## Benennung

`Referenz_Titel.md`. Die Referenz trägt Herkunft, Projekt, Jahr und laufende Nummer.

Die Reihe `YL-STAH-2026-###` ist neu angelegt. Liegt bei Yoline ein anderes
Aktenzeichen vor, werden die drei Dateien umbenannt und die Verweise im README
nachgeführt.

## Was hier nicht liegt

- Quelltexte, die eine Seite speisen. Die liegen in den Wörterbüchern unter `src/i18n/`
- Der Nachweis der Herkunft der ersten Texte. Der liegt in `content/archiv-2026-09/`
- Prüfskripte. Die liegen in `pruef/`, mit eigenem README
